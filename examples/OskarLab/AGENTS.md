# Lokaler Entwicklungsworkflow

Dienste über den eigenständigen Projekt-Starter starten: `dev.cmd start <Dienst>`.
Vorher `dev.cmd status` prüfen. Eine bereits laufende Instanz verwenden.
Logs: `dev.cmd logs <Dienst>` oder mit `--follow`.
Nur eigene, registrierte Dienste oder eindeutig zugeordnete Docker-Container stoppen.
Dev Orbit und IntelliJ müssen dafür nicht geöffnet sein.
Builds und Tests weiter über die vorhandenen npm-/Gradle-Aufgaben ausführen.
Bei Änderungen in Unterordnern deren AGENTS.md beachten.
